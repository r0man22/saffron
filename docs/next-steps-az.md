# ROFRAN: görülən işlər və növbəti mərhələ

## 15 oktyabr 2026: pulsuz araşdırma

Ahrefs Free Keyword Generator-da Azərbaycan üçün `zəfəran`, Rusiya üçün `шафран` sorğuları yoxlanılıb. Phrase match və Questions bölmələrində görünən nəticələr `keyword-research-az-ru.csv` faylında saxlanılıb. Ödənişli API çağırışı və abunəlik istifadə edilməyib.

Göstərilən `>100`, `<100`, `>1000` həcm aralıqları Ahrefs-in təxmini göstəriciləridir. Dəqiq aylıq həcm deyil. N/A və boş çətinlik göstəricisi rəqabətin sıfır olması demək deyil. Göstəricinin köhnə yenilənmə tarixi ola bilər. Rusiya nəticələri bütün rusdilli auditoriyanı təmsil etmir. Açar sözün uyğunluğu və səhifə seçimi bizim redaksiya qərarımızdır.

Əsas nəticə: zəfəran sözü üzrə aptek, xəstəxana, şəxs və digər biznes axtarışlarını ayırmaq lazımdır. Bu sorğular ədviyyat brendi üçün uyğun trafik deyil. Hazırda qiymət, dəmləmə, istifadənin izahı və məhsul seçimi daha uyğun mövzulardır; satış niyyətli məzmun real satış məlumatı tələb edir.

## Bu mərhələdə düzəldilənlər

- Zəfəranın istifadə və dəmləmə yazısı üç dildə daha praktik izahla yenilənib. Azərbaycan və rus başlıqları araşdırmada görünən suallara uyğunlaşdırılıb. Mövcud URL saxlanılıb.
- Dəyişən məqalənin yenilənmə tarixi ayrıca idarə olunur. Bütün yazıların tarixi avtomatik bu günə dəyişdirilmir.
- Sitemap şəkilləri məqalənin həqiqi şəklinə uyğunlaşdırılıb.
- Məlumat səhifəsi tamamlanıb `draft` statusu götürüldükdə sitemap-a avtomatik daxil olur. Natamam səhifə noindex olaraq qalır.
- Əsas domenin formatı yoxlanılır. Domen müəyyən edilmədən indeksləmə açıla bilmir. İnkişaf və Vercel preview mühitləri indekslənmir.

## Növbəti işlərin sırası

1. Real məhsul məlumatı: mənşə, tərkib, çəkilər, qablaşdırma, məhsul və partiya identifikatorları, mövcud keyfiyyət sənədləri.
2. Şirkət və əlaqə: hüquqi ad, ictimai e-poçt, telefon və varsa müştəriyə açıq ünvan. Saxta əlaqə məlumatı əlavə olunmur.
3. Sifariş: faktiki qəbul üsulu, qiymətlər, ödəniş, çatdırılma ölkələri və qaytarma şərtləri. WhatsApp müraciəti ilə sayt daxilində checkout fərqli funksiyalardır.
4. Real şəkillər: məhsul və qablaşdırma fotoşəkilləri; hər şəkil üçün təbii alt mətn.
5. Canlı yayımlama: alınmış əsas domen, HTTPS, hostinq və alternativ domenlərin uyğun alt səhifələrə yönləndirilməsi.
6. Ölçmə: Search Console və Bing Webmaster Tools-da təsdiq, sitemap və URL yoxlamaları. Analytics ayrıca müştəri davranışını ölçür; axtarış həcm aləti deyil.
7. Məzmun: mövcud materialları real məhsul təcrübəsi ilə gücləndirmək. Sınaqdan keçirilmiş reseptlər əlavə etmək. Coğrafi müqayisə və keyfiyyət fərqlərini mənbəsiz yazmamaq.
8. Dillər: çatdırılma və dəstək imkanı olan bazarları prioritetləşdirmək. Hazırda AZ/EN/RU aktivdir; digər 17 dil yalnız qeydiyyatdadır.

## Mənim edə biləcəyim işlər

Texniki SEO, məzmun və tərcümə hazırlamaq; real məlumatlar gəldikdə məhsul və şirkət səhifələrinə yerləşdirmək; şəkil ölçüləri və yüklənməni optimallaşdırmaq; səhifələri və bağlantıları yoxlamaq; yayımlama üçün konfiqurasiya hazırlamaq; canlı məlumatlar əlçatan olduqda nəticələri təhlil etmək.

## Sahibdən lazım olacaq məlumat

Məhsulun faktiki mənşəyi və çəkiləri, satış qiymətləri, şirkətin hüquqi və əlaqə məlumatları, çatdırılma/ödəniş/qaytarma qaydaları, məhsul fotoşəkilləri və həqiqi sənədlər. Domen və xarici hesab girişləri yalnız həmin mərhələdə lazımdır. Parolları çata yazmaq lazım deyil.

İndeksləmə hələ bağlıdır. Sayt, şirkət və məhsul məlumatları hazır olanda production domeni təsdiqlənərək aktivləşdiriləcək. Sıralama nəticəsi və AI detektoru barədə zəmanət verilmir.
